# Simulate the effects of a planar electric field at different frequencies on a realistic neuron

## Commands

Start NEURON GUI:

```{shell}
nrngui
```

Run .hoc file:

```{shell}
nrniv model.hoc
```

Run .hoc interactively:

```{shell}
nrniv model.hoc -
```

## Compile NMODL files

```shell
nrnivmodl
```
